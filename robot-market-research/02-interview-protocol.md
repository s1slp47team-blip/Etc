# 인터뷰 프로토콜 및 정량 설문 도구

전 페르소나에 **동일하게** 적용합니다. 페르소나별로 문항을 바꾸면 세그먼트 비교가 불가능해집니다.

---

## 실행 규칙

1. **페르소나 카드 + 이 프로토콜만 제공.** 다른 페르소나의 답변, 이전 회차 결과, 우리 제품 설명을 컨텍스트에 넣지 않습니다.
2. **순서 고정.** Q3(과거 행동) → Q6(거부 사유) → Q1/Q2(정량) → Q4/Q5/Q7 순서로 진행합니다.
   **니즈를 묻기 전에 과거 행동과 거부 사유를 먼저 뽑아내는 것이 핵심입니다.** 순서를 바꾸면 긍정 편향이 전 문항에 전염됩니다.
3. **미래 의향 질문 금지.** "도입하시겠습니까", "필요하십니까", "관심 있으십니까" 전부 사용하지 않습니다.
4. **정량 문항은 총합 고정 · 강제 선택.** "모두 중요합니다"를 구조적으로 불가능하게 만듭니다.
5. **페르소나당 3회 독립 실행.** 합의가 아니라 분산을 기록합니다.

---

## 도입 문구 (매 실행 동일하게 사용)

> 당신은 [페르소나 카드 내용]입니다. 이 인물로서, 실제 업무 경험에 근거해 답하십시오.
>
> 규칙:
> - 아는 것과 모르는 것을 구분하십시오. 모르는 건 "그건 제 소관이 아닙니다"라고 답하십시오.
> - 예의상 긍정하지 마십시오. 실제로 예산을 쓰지 않을 것이면 그렇게 말하십시오.
> - 숫자를 요구받으면 실제 업무에서 쓰는 단위로 답하십시오.
> - 이 대화는 영업이 아니라 조사입니다. 상대방을 만족시킬 필요가 없습니다.

## Q3 — 과거 행동 (가장 먼저)

> 최근 1년 안에, 인력이 부족하거나 사람이 하기 어려운 업무 때문에 곤란했던 상황을 하나 떠올려 주십시오.
> 1. 구체적으로 어떤 상황이었습니까? (시점, 장소, 업무)
> 2. **그때 실제로 어떻게 처리하셨습니까?** (검토만 한 것 말고, 실제로 한 행동)
> 3. 그 처리에 돈이 들었다면 얼마였습니까? 어느 예산 항목에서 나갔습니까?
> 4. 지금 같은 상황이 다시 오면 똑같이 처리하시겠습니까?

**분석 포인트:** 3번에서 **이미 지출하고 있는 예산 항목**이 나오면 그게 곧 로봇의 실제 경쟁 예산입니다. "아무것도 안 했다"가 나오면 통증이 지불 의사로 이어지지 않는 영역입니다.

## Q6 — 도입 저지 사유 (두 번째 · 니즈 질문보다 먼저)

> 어떤 로봇 서비스든, 귀사에 도입하려 할 때 무산될 이유를 **5개** 말씀해 주십시오.
> 5개를 다 채워야 합니다. 그리고 그중 **가장 먼저 문제가 될 1개**를 고르십시오.
> 각 사유에 대해: 그 문제를 실제로 제기할 사람은 누구입니까? (직책)

**분석 포인트:** 여기서 나오는 직책 목록이 실제 의사결정 지도입니다. 페르소나 본인이 언급하지 않은 직책이 다른 페르소나에서 반복 등장하면 페르소나 세트가 불완전하다는 신호입니다.

## Q1 — 예산 배분 게임

> 내년 시설 운영 개선 예산으로 **100포인트**가 배정되었습니다. 아래 12개 서비스에 배분하십시오.
> - 합계는 정확히 100이어야 합니다.
> - **0포인트를 받는 항목이 최소 6개 이상**이어야 합니다.
> - 한 항목에 50 이상 몰아도 됩니다.
> - 배분 후, 상위 2개 항목에 대해 **왜 그 비중인지** 한 문장씩 설명하십시오.

| S3 | 외벽 청소·고소작업 로봇 | |
| S4 | 설비 점검 로봇 | |

## Q2 — MaxDiff (강제 양극 선택)

> 12개 서비스 중에서:
> 1. **가장 먼저 도입할 것 1개** — 이유는?
> 2. **절대 도입하지 않을 것 1개** — 이유는? ("필요 없어서"는 답이 아닙니다. 도입하면 오히려 나빠지는 이유를 말하십시오)
> 3. **가장 판단하기 어려운 것 1개** — 무엇을 알아야 판단할 수 있습니까?

**분석 포인트:** 3번이 가장 중요합니다. "무엇을 알아야 판단 가능한가"에 대한 답이 곧 **영업 자료에 반드시 들어가야 할 정보**입니다.

## Q4 — 지불 의사 (WTP)

> 앞서 1순위로 고르신 서비스에 대해:
> 1. 현재 그 업무에 투입되는 **인건비는 월 얼마**입니까? (인원 × 단가)
> 2. 그 인력의 **몇 %를 대체**할 수 있어야 도입 검토가 시작됩니까?
> 3. **월 얼마**까지 지불 가능합니까? 그 금액은 어느 예산에서 나옵니까?
> 4. 회수기간이 **몇 년**을 넘으면 결재가 안 됩니까?
> 5. 만약 인력을 실제로 줄이지 못하고 로봇 비용만 추가된다면, 그래도 도입할 이유가 있습니까?

**5번이 핵심입니다.** 여기서 "없다"가 나오면 인건비 절감 논리는 무효고, "있다"가 나오면 그 이유(안전·법규·품질·커버리지)가 진짜 구매 동인입니다.

## Q5 — 계약 구조 선호

> 동일한 로봇 서비스를 세 가지 방식으로 제공합니다. **순위를 매기고**, 1순위 이유와 3순위 탈락 이유를 말씀하십시오.
>
> - **(A) 구매** — 초기 투자, 자산 계상, 유지보수 별도 계약
> - **(B) RaaS 월 구독** — 초기 비용 0, 월 이용료, 유지보수 포함, 계약 해지 시 반납
> - **(C) 성과 기반** — 기본료 최소, 절감액 또는 처리량에 연동해 정산
>
> 추가 질문:
> - (B)를 선택하신다면, 계약 기간이 **몇 개월** 이하여야 부담이 없습니까?
> - (C)의 성과 지표로 무엇을 쓰면 서로 다투지 않겠습니까?
> - 이 결정을 최종 승인하는 사람은 누구입니까? 그 사람의 판단 기준은 당신과 다릅니까?

## Q7 — Kano 분류

> 아래 각 항목에 대해 두 번 답하십시오.
> - **있으면** 어떻습니까? (① 당연하다 ② 좋다 ③ 상관없다 ④ 참아야 한다 ⑤ 싫다)
> - **없으면** 어떻습니까? (동일 척도)
>
> 대상: 24시간 무인 운영 / 기존 시스템(BMS·WMS·DCIM) 연동 / 자동 보고서 생성 / 원격 관제 / 이상 발생 시 알림 / 사람과 동일 공간에서 안전 주행 / 계약 해지 시 반납 가능

| 판정 | 의미 | 대응 |
|---|---|---|
| 있으면 ③ / 없으면 ⑤ | **필수 품질** | 없으면 논의 자체가 안 됨. 최우선 개발 |
| 있으면 ② / 없으면 ④ | **성능 품질** | 많을수록 좋음. 경쟁 요소 |
| 있으면 ② / 없으면 ③ | **매력 품질** | 차별화 포인트 |
| 있으면 ③ / 없으면 ③ | **무관심** | 개발 우선순위에서 제외 |

## Q8 — 마무리 (역질문)

> 1. 만약 사내에서 이 로봇 도입을 추진하신다면, **가장 먼저 설득해야 할 사람**은 누구입니까?
> 2. 그 사람이 던질 첫 질문은 무엇입니까?
> 3. 이 주제로 저희가 **반드시 만나봐야 할 사람**은 누구입니까? (직책)

**3번의 답이 다음 라운드 페르소나 세트를 결정합니다.** 예상 못한 직책이 나오면 페르소나를 추가하십시오.

## 3회 실행 결과 기록 양식

| 문항 | 1회차 | 2회차 | 3회차 | 분산 | 실제 인터뷰 필수 여부 |
|---|---|---|---|---|---|
| Q1 최상위 항목 | | | | 일치 / 분산 | |
| Q1 최상위 배분 점수 | | | | 편차 | |
| Q2 절대 거부 항목 | | | | 일치 / 분산 | |
| Q4 월 WTP | | | | 편차 | |
| Q4-5 인건비 절감 없이도 도입? | | | | 일치 / 분산 | |
| Q5 1순위 계약구조 | | | | 일치 / 분산 | |

**판정 기준**
- **3회 일치** → 모델의 강한 사전지식. 상식 수준이라 정보량이 낮습니다. 실제 인터뷰에서 확인만 하고 넘어가십시오.
- **2:1 분산** → 조건부 답변. 무엇이 조건인지 실제 인터뷰에서 파고들 것.
- **3회 전부 상이** → 모델도 모르는 영역. **실제 인터뷰 최우선 질문.** 여기에 시간을 쓰십시오.
- **WTP 편차 3배 이상** → 그 수치는 근거 없음. 인용 금지.
