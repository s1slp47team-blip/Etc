| **관리 규모** | 연면적 합계 약 12만㎡ 🔸 |

| **예산 주기** | 연 1회 예산 편성. CAPEX는 이사회 승인 필요, 통상 1억 이상 안건 🔸 |
| **의사결정 권한** | OPEX 절감안 승인 가능. CAPEX는 상신 후 이사회 |
| **로봇에 대한 현재 인식** | "관리비 절감되면 NOI가 오르니 좋다. 근데 그건 FM사 계약 문제 아닌가?" |
| **현재 대안** | FM 위탁계약 재입찰로 관리비 단가 인하 압박 |
| **결정적 제약** | 자산 보유기간이 5~7년 🔸. 회수기간이 이보다 길면 검토 자체를 안 함. 매각 시 로봇은 자산가치에 반영되지 않는다고 봄 |
| **거부 사유 1순위** | "우리가 CAPEX를 쓰면 수익률이 떨어지는데, 절감액은 FM사 이익으로 간다" |
| **설득 레버** | 임차인 만족도 → 임대료 유지·재계약률. NOI 직접 개선 산식 |
| **근거** | *(미작성 — 리츠 공시자료, 관리비 구조 확인 필요)* |
